# d-simya

Інтерактивні підказки до побутової техніки:

- `/` — пральна машина Beko WMB 71443 PTEB: кнопки, дисплей, перемикач програм, «Що прати», покрокова інструкція й типові проблеми.
- `/sushka/` — сушарка Gorenje SensoCare 6 кг: кнопки й лампочки, перемикач програм, «Що сушити», догляд і типові проблеми.

Сторінка працює як звичайний сайт і як Telegram Mini App (тема, кнопка «Назад» і вібрація підхоплюються автоматично).

Дані взяті з інструкцій Beko WMB 71243/71443/71643 PTE і Gorenje SP10.
