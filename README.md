# D-SIM’YA

Telegram Mini App для життя в Німеччині: домашні помічники для родини в Ксантені (NRW).

- **Пральна машина й сушарка**: кнопки, програми, що прати й сушити, типові проблеми.
- **Сканер документів**: фото аркуша стає рівною сторінкою PDF; документ можна перекласти (німецька → українська, українська → німецька, англійська → українська).
- **Сміття**: дати вивозу для свого району Ксантена й нагадування в Telegram напередодні.
- **Проспекти**: акції магазинів Ксантена й Везеля на поточний тиждень, свята й неділі, коли магазини зачинені.

Сторінки — статичний сайт на GitHub Pages, що працює і як звичайний сайт, і всередині Telegram.
Невеликий сервер на Cloudflare Workers робить те, чого сторінка сама не може: надсилає повідомлення й файли від бота та перекладає текст.
Фото обробляються на пристрої; на сервер іде лише те, що потрібно для дії, яку ти вибрав.

Сторонні частини: шрифт Noto Sans (SIL Open Font License, [`assets/fonts/`](assets/fonts/)); розпізнавання тексту [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache 2.0), яке завантажується з jsDelivr і перевіряється за хешем офіційного випуску.
Дані про пральку й сушарку взято з інструкцій Beko WMB 71243/71443/71643 PTE та Gorenje SP10.
