# Сервер D-SIM’YA (Cloudflare Worker)

Робить те, чого статичні сторінки зробити не можуть:

- надсилає PDF зі сканера в чат із ботом;
- на кілька хвилин передає відскановані сторінки з Telegram у браузер телефона;
- перекладає розпізнаний текст сторінки (Gemma 4 на Workers AI);
- надсилає нагадування: про вивіз сміття напередодні ввечері й про нові проспекти щопонеділка;
- приносить відправлення з зупинок (VRR OpenService), погоду (Open-Meteo) і попередження DWD для сторінок «Транспорт» і «Погода»;
- пише про нові попередження DWD і надсилає «Слово дня» тим, хто це ввімкнув;
- зберігає спільний список покупок родини (Durable Object: зміни з двох телефонів ніколи не затирають одна одну).

Захист: кожен запит, що діє від імені людини, має підпис Telegram, який сервер перевіряє токеном бота; відповіді й файли йдуть лише тому, хто підписав запит; токен зберігається тільки в налаштуваннях Cloudflare.

Доступ мають лише додані мною люди.

Розклад і погода — публічні дані, тож підпис для них не потрібен: сервер перевіряє лише сам запит (номер зупинки, текст пошуку, координати), округлює місце приблизно до кілометра й тримає відповіді недовго (30 секунд для відправлень, 10 хвилин для погоди), щоб не навантажувати VRR і Open-Meteo. Частоту таких запитів обмежено.
